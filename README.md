# 🐍 Jornada Python

Minicurso oferecido pela **Hashtag Treinamentos**, com o objetivo de apresentar os fundamentos de Python e demonstrar sua aplicação em projetos práticos e situações reais.

Ao longo de quatro aulas, serão desenvolvidos projetos que exploram diferentes áreas da programação, desde a automação de tarefas até a inteligência artificial e o desenvolvimento de sistemas.

## 📚 Projetos

<details>
  <summary>🤖 Aula 1 — Automação e Bots</summary>

  Projeto de automação de tarefas repetitivas utilizando Python e a biblioteca PyAutoGUI. A aplicação automatiza o acesso a um sistema web, realiza o login e cadastra produtos a partir de uma base de dados CSV, utilizando Pandas.

  **Conceitos:** automação, PyAutoGUI, Pandas e manipulação de arquivos CSV.

  📂 [Acessar os arquivos da Aula 1](./Aula%201/)

</details>

<details>
  <summary>📊 Aula 2 — Análise de Dados</summary>

  Projeto voltado à análise de dados com Python, explorando a importação, organização, tratamento e análise de informações para extrair resultados relevantes.

  **Conceitos:** Python, Pandas e análise de dados.

  📂 [Acessar os arquivos da Aula 2](./Aula%202/)

</details>

<details>
  <summary>🤖 Aula 3 — Chatbot com IA em Tempo Real</summary>

  Desenvolvimento de um chatbot com inteligência artificial, explorando a integração com modelos de IA e a criação de interações em tempo real.

  **Conceitos:** Python, inteligência artificial e chatbots.

  📂 [Acessar os arquivos da Aula 3](./Aula%203/)

</details>

<details>
  <summary>🛒 Aula 4 — Sistema de Vendas e Gestão Online</summary>

  Desenvolvimento de um sistema online voltado ao gerenciamento de vendas, com funcionalidades para cadastrar e visualizar as vendas de produtos realizadas, além de acompanhar alguns indicadores e métricas por meio de gráficos.

  **Conceitos:** Python, desenvolvimento de sistemas e gestão online.

  📂 [Acessar os arquivos da Aula 4](./Aula%204/)

</details>

---

## 🎯 Objetivo

Aplicar os conhecimentos adquiridos em Python por meio de projetos práticos, desenvolvendo habilidades de programação e resolução de problemas.
