# 🤖 Aula 1 - Automação e bots

Projeto desenvolvido durante a aula 1 da Jornada Python, da Hashtag Treinamentos, com o objetivo de aplicar conceitos básicos de automação de tarefas repetitivas utilizando Python.

## 📌 Sobre o projeto

O projeto consiste em uma automação que realiza o cadastro de produtos em um sistema web a partir de uma base de dados armazenada em um arquivo CSV.

Por meio da biblioteca PyAutoGUI, o programa automatiza a interação com o navegador, acessa o sistema de cadastro, realiza o login e preenche os campos necessários para registrar os produtos.

O principal objetivo é compreender, na prática, como a automação pode simplificar tarefas manuais e repetitivas, reduzindo a necessidade de intervenção humana em processos operacionais.

## ⚙️ Funcionalidades

* 🌐 Abertura automática do navegador Google Chrome.
* 🔗 Acesso ao sistema web de cadastro de produtos.
* 🔐 Realização automática do login.
* 📂 Leitura de uma base de dados de produtos em formato CSV utilizando Pandas.
* 📝 Preenchimento automatizado dos campos de cadastro.
* 📦 Cadastro dos produtos no sistema web.

## 🛠️ Tecnologias utilizadas

* Python: linguagem utilizada para desenvolver a automação.
* PyAutoGUI: biblioteca responsável por automatizar as interações com o teclado e o mouse.
* Pandas: biblioteca utilizada para ler e manipular os dados do arquivo CSV.
* Time: módulo utilizado para controlar os intervalos de execução e aguardar o carregamento das páginas.

## 📊 Base de dados

Os produtos utilizados na automação são armazenados em um arquivo CSV, que contém as informações necessárias para realizar os cadastros no sistema.

O Pandas é utilizado para importar e organizar esses dados, permitindo que o programa percorra os registros e automatize o preenchimento dos campos.

## 🎯 Aprendizados

O desenvolvimento deste projeto proporcionou uma introdução prática a conceitos importantes de Python, como:

* Importação e utilização de bibliotecas.
* Manipulação e leitura de arquivos CSV com Pandas.
* Automação de tarefas com PyAutoGUI.
* Utilização de comandos para interação com páginas web.
* Organização e execução de scripts Python.
* Aplicação da lógica de programação na resolução de tarefas repetitivas.

## ⚠️ Observações

A automação utiliza coordenadas de tela para realizar cliques e interagir com o sistema. Por esse motivo, seu funcionamento pode variar de acordo com a resolução do monitor, o tamanho da janela e possíveis alterações no layout da página.

O acesso ao sistema é feito utilizando o e-maildefinido no código. No ambiente de treinamento utilizado durante a aula, a senha pode ser preenchida com qualquer valor, pois a validação do acesso depende do e-mail informado.

Este projeto foi desenvolvido para fins educacionais, como parte das atividades práticas da Jornada Python, da Hashtag Treinamentos.
